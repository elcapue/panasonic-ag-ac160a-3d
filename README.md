# Panasonic AG-AC160A: интерактивная 3D-схема

**index.html** — готовая страница, открывается двойным кликом и работает без интернета.
Камеру можно вращать мышью или клавишами WASD / стрелками, колесо или Q / E приближает, правая кнопка или Shift + WASD / стрелки сдвигает вид. Клавиши [ и ] (или PageUp / PageDown) листают элементы в экскурсии, Esc закрывает карточку. Клик по кнопке, переключателю или разъёму открывает описание, при этом элемент «срабатывает»: запись включает тали-лампы, BARS выводит полосы на экран, крышки разъёмов открываются.

## Как править
- `source/src/data.js` — все описания и положения элементов (face / a / b). Тексты можно менять прямо здесь.
- `source/src/main.js` — геометрия камеры, анимации, экран, интерфейс.
- `source/src/template.html` — вёрстка и стили.

Пересборка (нужен Node.js 18+), в папке `source`:
```
npm install
npm run build
```
Результат появится в `source/dist/index.html`, его нужно скопировать на место `index.html`.

Источники: инструкция AG-AC160A Vol.1 (с. 21–23, названия частей) и Vol.2, фото реальной камеры (`references/photos`), рендеры модели TurboSquid (`references/3d model screenshots`).
Положение кнопки AWB на модели примерное.

## Сверка с фото
Силуэт сбоку подогнан наложением на `references/photos/ref_10.jpg` (масштаб ≈ 41,5 px на единицу модели), нижняя панель — по `ref_08.jpg`.
Для таких сравнений есть dev-сервер: `python source/snapserver.py 5178` отдаёт `source/dist` и сохраняет снимки в `_snaps/`.
В консоли страницы: `__snap(имя, [dx,dy,dz], дистанция, [цель], w, h, fov, orthoHalfWidth)` — один кадр,
`__views('v1')` — набор ракурсов (слева, справа, спереди, сзади, сверху, 3/4 и кадр, совмещённый с ref_10).
